⚠️ Reset Semua Data Lokal

Menghapus seluruh data aplikasi yang tersimpan di browser ini: master pemain, sesi dan jadwal, skor, semua arsip lama, arsip hari ini, poin, serta statistik menang/seri/kalah. File backup yang sudah diunduh dan data Firebase tidak ikut terhapus.

Apakah Anda yakin?

Semua arsip dan rekaman lama, termasuk data hari ini, akan dihapus dari penyimpanan lokal browser. Master pemain, jadwal, skor, poin, dan statistik menang/seri/kalah juga akan dikosongkan.

Tindakan ini tidak dapat dibatalkan dari aplikasi. Pastikan Anda sudah mengunduh backup jika masih membutuhkannya.

Unggah Arsip Sebelumnya

☁️ Konfigurasi Firebase Cloud

Konfigurasi proyek winnerpadel sudah diisi otomatis. Konfigurasi disimpan di browser ini. Aktifkan Authentication (Anonymous) dan Cloud Firestore pada Firebase Console sebelum menyambungkan.
