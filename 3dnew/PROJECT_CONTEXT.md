# Divalicious Studio — Project Context

Repository folder: `3dnew/`
Repository URL: https://github.com/fakecuan/web/tree/main/3dnew

## Purpose

This folder is a working source area for the Divalicious Studio 3D product catalog and related web experience.

## Working context

Use this folder as the reference for:
- 3D-printed product catalog entries, product names, and descriptions.
- Adding new product designs and checking for visually or functionally similar existing products before adding duplicates.
- Catalog layout, HTML/CSS/JavaScript behavior, and related product assets.
- Product preview and customer-facing catalog improvements.

## Working rules

1. Inspect the existing files and structure in `3dnew/` before making changes.
2. Preserve existing functionality and visual conventions unless a change is explicitly requested.
3. Reuse existing assets and product entries where appropriate; avoid duplicate catalog entries.
4. Keep product names and descriptions clear and suitable for Divalicious Studio customers.
5. When updating the catalog, update the relevant source files and assets together, and report the exact files changed.
6. Do not claim a change has been deployed or committed unless the GitHub operation succeeds.

This file records project context and working guidance. It does not replace the actual application source or catalog data.
