# Instructions for working in `3dnew/`

This file is the operational instruction entry point for coding assistants and contributors working in this directory.

Before making any change in this folder:
1. Read `PROJECT_CONTEXT.md` for the Divalicious Studio project purpose and working rules.
2. Inspect the current application files and assets; do not assume the folder structure or rewrite files blindly.
3. Identify the actual catalog data/source and preserve existing behavior, styling, and customer workflows.
4. Check existing product entries and images before adding a new catalog item. Avoid duplicates and near-duplicates; explain any uncertain match.
5. Make only the requested changes. Keep related HTML, CSS, JavaScript, and assets consistent.
6. Verify the changed files and summarize exactly what changed. Never claim deployment unless it was actually performed.

## Project scope

The `3dnew/` directory belongs to Divalicious Studio and is used for its 3D product catalog and related customer-facing web experience. Relevant work includes product catalog entries, product names and descriptions, design/asset additions, product previews, and catalog UI improvements.

## Important

Do not treat `PROJECT_CONTEXT.md` as application code or insert project notes into the customer-facing UI. These instructions guide development work only.
